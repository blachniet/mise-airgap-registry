Fork-owned tools that exist only inside the airgap, not on the internet. Each `<name>.toml` uses the same format as `tools/*.toml`, with its internal URL, and becomes `airgap:<name>` (or `<prefix>:<name>` if `mirror.toml` sets `prefix`). Upstream adds no tools here. Names must not collide with `tools/*.toml`, `mirror.toml` doesn't apply, and `mise run urls` reports nothing to mirror.
